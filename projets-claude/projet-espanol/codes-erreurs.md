# Codes d'erreurs (à utiliser dans chaque correction)

| Code | Type d'erreur | Exemple |
|---|---|---|
| CONC | Concordance genre, nombre, personne | los dientes blanca → blancos |
| TV | Temps ou mode verbal | ayer he ido → fui ; quiero que vienes → vengas |
| S/E | Ser / estar / hay | es cansado → está cansado |
| PREP | Préposition, régime du verbe | pienso a ti → en ti |
| PRON | Pronom, place, leísmo | le vi (a ella) → la vi |
| LEX | Mot faux, faux ami, collocation | realizar que → darse cuenta de que |
| ORT | Orthographe, tilde, majuscule | Lunes → lunes ; medico → médico |
| SINT | Ordre des mots, structure | la blanca dentina → la dentina blanca |
| REG | Registre, connecteur inadapté | yo pienso que… → cabe señalar que… |

Règles de comptage : une erreur = une occurrence ; la même faute répétée trois fois compte trois fois (c'est ce qui coûte à l'examen). Erreurs pour 100 mots = erreurs × 100 / nombre de mots. Le code dominant est celui qui représente le plus d'occurrences ; s'il dépasse 30 % du total, il devient le point de grammaire de la semaine suivante.

Format d'une carte d'erreur : `Phrase avec {{c1::forme juste::indice}}<TAB>Règle en une phrase, en espagnol<TAB>errores CODE`.
