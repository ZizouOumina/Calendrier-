# Vocabulaire espagnol — liste de lecture

Les 485 phrases du deck « Español · Batcave », par sous-deck, dans l'ordre d'étude. La forme à retenir est en gras ; la colonne de droite est l'explication du verso, en espagnol. À lire à voix haute ; les cartes Anki servent à la mémorisation, cette liste à la révision d'un coup d'œil.

## 2 Gramática (65)

| Phrase | Explication |
|---|---|
| **Soy** estudiante de Odontología. | Ser: identidad, profesión, origen, características permanentes. |
| Hoy **estoy** cansado. | Estar: estado, resultado, posición, lugar. |
| La clase **está** muy bien explicada. | 'Bien' y 'mal' son adverbios: siempre con estar. Con ser: bueno / malo. |
| Este manual **es** muy bueno. | Cualidad → ser + bueno. Estado → estar + bien. |
| La biblioteca **está** cerca del tranvía. | Lugar de una cosa o persona → estar. |
| El examen **es** en el aula 3. | Lugar de un evento (examen, clase, reunión) → ser. |
| **Hay** muchos estudiantes en clase. | Existencia → hay (invariable). 'Están' se usa con sujeto determinado: los estudiantes están en clase. |
| Ayer **fui** al dentista y hoy **he ido** a clase. | Marcador de tiempo cerrado (ayer, en 2020) → indefinido. Tiempo abierto (hoy, esta semana, ya) → perfecto. |
| De niño, **iba** al colegio en bici. | Hábito o descripción en el pasado → imperfecto. |
| Cuando llegué, el profesor ya **había empezado**. | Acción anterior a otra acción pasada → pluscuamperfecto (había + participio). |
| A María **la** vi ayer. | Objeto directo: lo / la / los / las. 'Le' es objeto indirecto (con 'a' de persona, solo se admite 'le' para hombre). |
| A Juan **le** di los apuntes. | Objeto indirecto: le / les. Con lo/la delante se convierte en 'se': se los di. |
| El libro **lo** dejé en casa. | Objeto directo masculino singular → lo. |
| Me **gustan** los dientes sanos. | Gustar concuerda con lo que gusta: me gusta el café, me gustan los dientes. |
| Pienso **en** el examen. | Régimen: pensar en, depender de, consistir en, soñar con, tratar de, casarse con, enamorarse de. |
| Todo depende **de** la nota. | depender de. |
| El tratamiento consiste **en** tres sesiones. | consistir en. |
| Sueño **con** ser dentista. | soñar con. |
| Trato **de** hablar solo español. | tratar de + infinitivo = intentar. |
| Empiezo **a** entender las clases. | empezar a, aprender a, ayudar a, volver a. |
| He dejado **de** hablar francés en la facultad. | dejar de + infinitivo = parar de. Acabar de + inf. = hace muy poco. |
| Estudio **para** aprobar. | Para: finalidad, destinatario, plazo, dirección. |
| Gracias **por** tu ayuda. | Por: causa, medio, precio, lugar por donde se pasa, tiempo aproximado. |
| Paso **por** el centro para ir a la facultad. | por = a través de. |
| Este libro es **para** ti. | para = destinatario. |
| Lo compré **por** diez euros. | por = precio, intercambio. |
| Tengo que entregarlo **para** el lunes. | para = fecha límite. |
| Quiero que **vengas** a la biblioteca. | Verbos de voluntad, deseo, orden + que → subjuntivo. |
| Creo que **es** fácil. | Opinión afirmativa → indicativo. |
| No creo que **sea** fácil. | Opinión negada, duda → subjuntivo. |
| Cuando **termine** la clase, te escribo. | Temporal referida al futuro → subjuntivo. Hábito → indicativo: cuando termina la clase, siempre me voy. |
| Si **tuviera** tiempo, iría al intercambio. | Condicional irreal: si + imperfecto de subjuntivo, condicional. Nunca condicional después de 'si'. |
| Si **tengo** tiempo, iré al intercambio. | Condición real: si + presente, futuro / presente / imperativo. |
| Tengo **otro** examen el viernes. | Otro nunca lleva 'un': otro día, otra vez. |
| La gente **es** muy amable aquí. | Gente es singular: la gente es, la gente dice. |
| Hablo **muy** bien, pero cometo **muchos** errores. | Muy + adjetivo o adverbio. Mucho + nombre, o después de verbo (trabajo mucho). |
| — No entiendo la pregunta. — Yo **tampoco**. | Acuerdo con una negación → tampoco. Con afirmación → también. |
| **Tengo** diecinueve años. | Tener: años, hambre, sed, sueño, frío, calor, miedo, razón, prisa. |
| Estudio español **desde hace** dos semanas. | Duración: desde hace + tiempo; hace + tiempo + que; llevar + tiempo + gerundio. |
| **Llevo** dos años viviendo en Alicante. | llevar + tiempo + gerundio = hace X que. |
| **Estoy** de acuerdo contigo. | estar de acuerdo con (nunca 'ser'). |
| Voy a **pedir** un favor al profesor. | Pedir = solicitar algo. Preguntar = hacer una pregunta. |
| Voy a **preguntar** al profesor si hay examen. | preguntar si / preguntar por alguien. |
| **Son** las tres y media. | Ser concuerda con la hora: es la una, son las dos. |
| El examen es el **lunes** 16 de **noviembre**. | Días, meses, idiomas y gentilicios van en minúscula: lunes, noviembre, español, francés. |
| Me he **dado cuenta** de que necesito más práctica. | darse cuenta de = percatarse. 'Realizar' = hacer, llevar a cabo. |
| Tengo tos y mocos: estoy **constipado**. | constipado = resfriado. Para el intestino: estreñido. |
| Mi hermana está **embarazada**. | embarazada = que espera un hijo. 'Avergonzado' = que siente vergüenza. |
| El pasillo es muy **largo** y bastante **ancho**. | largo = de gran longitud; ancho = de gran anchura; estrecho = poco ancho. |
| La enfermera **atiende** a los pacientes. | atender = ocuparse de. Asistir a = estar presente en (asistir a clase). |
| El congreso fue un **éxito**. | éxito = triunfo. Salida = lugar por donde se sale. Suceso = acontecimiento. |
| La **salida** de emergencia está a la derecha. | salida ≠ éxito. |
| ¿**Qué** hora es? | Interrogativos y exclamativos llevan tilde: qué, cuál, quién, dónde, cuándo, cómo, cuánto. |
| **Quítate** la chaqueta, hace calor. | quitar = retirar, sacar. Quitarse = retirar de uno mismo. |
| **Sube** las escaleras, la clase es en el primer piso. | subir = ir hacia arriba. Salir = ir fuera. |
| No me **molestes**, estoy estudiando. | molestar = incomodar, importunar. |
| Necesito una **carpeta** para los apuntes. | carpeta = donde se guardan papeles. Alfombra = tejido para el suelo. |
| Tengo un **rato** libre a las dos. | rato = momento breve. Rata = animal. |
| Un **vaso** de agua, por favor. | vaso = recipiente para beber (y vaso sanguíneo). Jarrón = para flores. |
| Mi **apellido** es Oumina. | nombre = de pila; apellido = de familia. |
| El **suelo** del laboratorio está mojado. | suelo = superficie donde se pisa. Sol = la estrella. |
| Se me ha **olvidado** el libro en casa. | Se me olvidó / se me cayó / se me rompió: acción involuntaria. |
| **Se** observa una lesión en el molar. | Pasiva refleja: se + verbo en 3.ª persona. Registro científico: se observa, se produce, se ha demostrado. |
| Es un molar **sano**. | sano = con salud. 'Sensible' = que siente mucho; 'sensato' = que tiene juicio. |
| El paciente **eventualmente** nota dolor; **posiblemente** sea la encía. | eventualmente = ocasionalmente. Para 'quizás': posiblemente, tal vez, en su caso. |

## 4 Conectores (42)

| Phrase | Explication |
|---|---|
| **Además**, el esmalte protege la dentina. | Adición. Sinónimos: asimismo, igualmente, por otra parte. |
| **Asimismo**, se observa inflamación de la encía. | Adición formal. |
| **Por otra parte**, el coste del tratamiento es elevado. | Añadir un aspecto distinto. |
| **Sin embargo**, la dentina es sensible. | Oposición. Sinónimo formal: no obstante. |
| **No obstante**, existen excepciones. | Oposición, registro formal. |
| La caries avanza lentamente; **en cambio**, un traumatismo es inmediato. | Contraste entre dos elementos. |
| El esmalte es duro, **mientras que** la pulpa es blanda. | Contraste. |
| **Ahora bien**, no todos los pacientes responden igual. | Introduce una restricción. |
| **A pesar de que** estudió mucho, suspendió. | Concesión + verbo conjugado. Con nombre: a pesar de / pese a + nombre. |
