# Les pièges du francophone (à traquer en priorité dans mes textes)

| J'écris | Il faut | Règle |
|---|---|---|
| Estoy estudiante. | Soy estudiante. | Ser : identité, profession, origine. |
| Es cansado. | Está cansado. | Estar : état, résultat, position. |
| Es muy bien. | Está muy bien. / Es muy bueno. | Bien est un adverbe, jamais avec ser. |
| Ayer he ido al dentista. | Ayer fui al dentista. | Marqueur de passé révolu = indefinido. Perfecto pour hoy, esta semana, ya. |
| De niño, fui al colegio cada día. | De niño, iba al colegio cada día. | Habitude passée = imperfecto. |
| Le vi (a María). | La vi. | OD féminin = la ; le = OI. |
| Me gusta los dientes. | Me gustan los dientes. | Gustar s'accorde avec la chose aimée. |
| Pienso a ti. | Pienso en ti. | Pensar en, depender de, consistir en, soñar con, tratar de. |
| Voy al médico por ver. | Voy al médico para ver. | Para = but ; por = cause, moyen, échange, lieu traversé. |
| Quiero que vienes. | Quiero que vengas. | Volonté + que = subjonctif. |
| No creo que es difícil. | No creo que sea difícil. | Opinion niée = subjonctif ; creo que = indicatif. |
| Cuando llegaré, te llamo. | Cuando llegue, te llamo. | Temporelle au futur = subjonctif. |
| Si tendría tiempo, iría. | Si tuviera tiempo, iría. | Jamais de conditionnel après si. |
| un otro problema | otro problema | Otro sans article indéfini. |
| La gente son simpáticos. | La gente es simpática. | Gente est singulier. |
| mucho bien / muy libros | muy bien / muchos libros | Muy + adjectif ou adverbe ; mucho + nom. |
| Yo también no. | Yo tampoco. | Négation en accord = tampoco. |
| Soy veinte años. | Tengo veinte años. | Tener pour l'âge, la faim, le sommeil, le froid. |
| Estudio español desde dos años. | Estudio español desde hace dos años. / Llevo dos años estudiando. | Durée : desde hace, hace… que, llevar + gérondif. |
| Soy de acuerdo. | Estoy de acuerdo. | Estar de acuerdo con. |
| Preguntar un favor. | Pedir un favor. | Pedir = demander une chose ; preguntar = poser une question. |
| Es las tres. | Son las tres. / Es la una. | Ser s'accorde avec l'heure. |
| el Lunes, en Septiembre, el Español | el lunes, en septiembre, el español | Pas de majuscule aux jours, mois, langues. |
| He realizado que… | Me he dado cuenta de que… | Realizar = effectuer. |
| Estoy constipado (pour « constipé »). | Estoy estreñido. | Constipado = enrhumé ; embarazada = enceinte. |
| un largo pasillo (pour « large ») | un pasillo ancho | Largo = long ; ancho = large. |
| Asistir a un paciente. | Atender a un paciente. | Asistir a = assister à ; atender = s'occuper de. |
| Es un éxito (pour « une sortie »). | Es una salida. | Éxito = succès ; salida = sortie ; suceso = événement. |
| eventualmente (pour « éventuellement ») | posiblemente / en su caso | Eventualmente = occasionnellement. |
| ¿Que hora es? | ¿Qué hora es? | Tilde sur l'interrogatif ; ¿ ¡ ouvrants. |

Autres faux amis : quitar (enlever) · salir (sortir) · subir (monter) · molestar (déranger) · sensible (sensitif) / sensato (sensé) · carpeta (chemise) / alfombra (tapis) · débil (faible) · demandar (poursuivre en justice) / pedir · discutir (se disputer) · entender (comprendre) / oír (entendre) · equipaje (bagages) / equipo (équipe) · gato (chat) · nombre (nom) / número (nombre) · pie (pied) / tarta (tarte) · rato (moment) / rata (rat) · ropa (vêtements) / cuerda (corde) · sol (soleil) / suelo (sol) · vaso (verre) / jarrón (vase) · mesa (table) / misa (messe) · contestar (répondre) · apellido (nom de famille) · exprimir (presser) / expresar · bizarro (courageux) / raro · cuello (cou, et collet de la dent).

## Prononciation (à me rappeler quand je te dicte)
Accent tonique mot par mot ; cinq voyelles pures, toutes prononcées ; r simple battu / rr roulé ; jota raclée ; z, ce, ci = /θ/ (distinción, norme d'Alicante) ; b = v ; d intervocalique douce, d final presque muette ; h muette.
