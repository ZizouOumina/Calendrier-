# Trois Projets Claude à créer

Dans claude.ai : menu **Projets** → **Créer un projet** → nom → dans le panneau de droite,
**Instructions** (colle le contenu de `instructions.md`) et **Connaissances du projet**
(glisse les autres fichiers du dossier). Toutes les conversations ouvertes dans le projet
héritent des instructions et des documents.

- `projet-dentaire/` → Projet « Dentaire ». Un Projet n'a pas d'onglets : chaque matière est un fichier dans `matieres/` (glisse-les tous dans Connaissances) et une conversation renommée au nom de la matière. Le tuteur lit le fichier de la matière dès que tu la nommes.
- `projet-boutique/` → Projet « Boutique ».
- `projet-espanol/` → Projet « Español ». Instructions dans `instructions.md` ; en Connaissances : `plan-et-grille.md`, `pieges-francophone.md`, `codes-erreurs.md`, `progresion.md` (à remplir chaque dimanche, puis remplacer dans le projet). Les commandes : corrige, interroga, examen, explica (question non comprise, réponse en français), conversa, cartas, dictado, formulas, balance.

Les fichiers marqués « à compléter » se remplissent au fil des semaines (avatar, offre, ton).
Remplace-les dans le projet quand ils changent : le projet ne se met pas à jour tout seul.
